# Bitácora Arcade

Una trivia geek de tres preguntas: cada acierto desbloquea un valor RGB y al final se revela el color con su código hexadecimal. La pestaña Histórico contiene una muestra de diez concursos de Tris y diez de Melate. Los datos históricos están guardados en `archivo.js`; no se actualizan en tiempo real.

## Probar en local

Abre `index.html` en tu navegador. La aplicación usa HTML, CSS y JavaScript y funciona sin instalar dependencias.

## Publicar con GitHub Pages

1. Sube los archivos a la rama `main` de tu repositorio. Deja `index.html`, `style.css`, `archivo.js`, `app.js` y `.nojekyll` en la raíz.
2. En **Settings → Pages → Build and deployment**, elige **Deploy from a branch**.
3. Selecciona **main** y **/ (root)**, y pulsa **Save**.
4. Cuando termine el despliegue, abre **Visit site** en esa misma página. Para un repositorio de proyecto, la dirección habitual es `https://USUARIO.github.io/REPOSITORIO/`.

Los cambios que subas a `main` se publicarán automáticamente. Los enlaces a los recursos son relativos, así que puedes elegir cualquier nombre de repositorio.
